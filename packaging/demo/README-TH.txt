ชุดทดลองใช้งานระบบออกแบบหลักสูตร
==================================

สิ่งที่ต้องมี
- เครื่อง Windows ที่ติดตั้ง Docker Desktop แล้ว (เปิดโปรแกรมทิ้งไว้ให้ขึ้นสถานะ running) และใช้โหมด Linux containers ซึ่งเป็นค่าเริ่มต้น
- อินเทอร์เน็ต เพราะระบบเรียกใช้โมเดลภาษาผ่านบริการออนไลน์

วิธีเริ่มใช้งาน
1. คลิกขวาที่ไฟล์ zip เลือก Extract All (แตกไฟล์ทั้งหมด) แล้วเปิดโฟลเดอร์ที่แตกออกมา อย่าดับเบิลคลิกไฟล์ภายใน zip โดยตรง
   หาก Windows แจ้งเตือนว่าเป็นไฟล์ที่ดาวน์โหลดมา ให้กด Run หรือกด More info แล้วเลือก Run anyway
2. ดับเบิลคลิกไฟล์ start.cmd ในโฟลเดอร์ที่แตกออกมา
3. การเริ่มครั้งแรกใช้เวลาหลายนาที เพราะต้องติดตั้งโปรแกรมและโหลดข้อมูลตัวอย่าง กรุณารอจนเบราว์เซอร์เปิดขึ้นเอง
4. หากเบราว์เซอร์ไม่เปิด ให้เข้าที่ http://127.0.0.1:8765/

วิธีหยุดใช้งาน
- ดับเบิลคลิกไฟล์ stop.cmd ข้อมูลที่คุณทำไว้จะยังอยู่ครบ เมื่อเริ่มใหม่ด้วย start.cmd จะทำงานต่อได้ทันที

วิธีเริ่มใหม่จากตัวอย่างเดิม
- ดับเบิลคลิกไฟล์ reset.cmd ระบบจะคืนค่ากลับเป็นตัวอย่างชุดเดิมที่มากับโปรแกรม
- คำเตือน: การรีเซ็ตจะลบงานและข้อมูลที่คุณสร้างหรือแก้ไขไว้ทั้งหมด และกู้คืนไม่ได้

หมายเหตุ
- หากพอร์ต 8765 ถูกโปรแกรมอื่นใช้อยู่ ให้เปิดไฟล์ .env ด้วยโปรแกรม Notepad แล้วเปลี่ยนเลขหลัง APP_PORT= เป็นเลขอื่น เช่น 8766 (ที่อยู่เว็บจะเปลี่ยนตามเลขนั้น)
- ชุดนี้ใช้ทดลองบนเครื่องนี้เท่านั้น ไม่ได้ออกแบบให้เปิดใช้งานให้ผู้อื่นเข้าถึงผ่านเครือข่าย
- ห้ามแชร์โฟลเดอร์นี้ให้ผู้อื่น เพราะไฟล์ .env มีรหัสสำหรับเชื่อมต่อบริการ
