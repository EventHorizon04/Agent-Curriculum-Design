## Question

ก่อนจะให้ designer เขียน scope statement เป็น free text ขึ้นมาใหม่ทั้งดุ้น — มีมาตรฐานหรือ
taxonomy ที่นิยาม "ขอบเขตสาขาวิชา" ของหลักสูตรอุดมศึกษาไทยไว้อยู่แล้วหรือไม่ และมันบอกอะไรได้บ้าง

ต้องได้คำตอบสามข้อ:

1. **ISCED-F 2013** (ฟิลด์ `isced_code` ค้างอยู่บน `ProgramMetadata` แล้ว) — ระดับ narrow/detailed
   field ให้คำอธิบายขอบเขตแบบข้อความไหม หรือให้แค่รหัสกับชื่อ? ถ้ามีคำอธิบาย มันละเอียดพอจะ
   ใช้เป็นตัวตั้งต้นให้ designer แก้ต่อแทนหน้ากระดาษเปล่าไหม
2. **มคอ.1 (มาตรฐานคุณวุฒิระดับอุดมศึกษาสาขา/สาขาวิชา)** — เอกสารนี้ระบุขอบเขตสาขาไว้เป็นหมวด
   อะไร ใช้ถ้อยคำแบบไหน มีตัวอย่างที่ยกมาอ้างได้ไหม (repo มี `parsers/` สำหรับ มคอ.1 อยู่แล้ว)
3. **AUN-QA** — criterion ที่ว่าด้วย Expected Learning Outcomes พูดถึงการกำหนดขอบเขต /
   distinctiveness ของหลักสูตรไว้ยังไง

ผลลัพธ์ที่ต้องการ: เอกสาร Markdown สรุปว่าแต่ละแหล่งให้อะไรได้จริง พร้อมตัวอย่างถ้อยคำจริง
2-3 ตัวอย่างต่อแหล่ง เพื่อให้ ticket 02 เอาไปตัดสินว่า scope statement ควรเป็นกระดาษเปล่า
หรือเป็นแบบฟอร์มที่มีของตั้งต้น

**ขอบเขต**: อ่านแหล่งปฐมภูมิเท่านั้น (เอกสาร อว., UNESCO ISCED, AUN-QA guide) ไม่ต้องเสนอ
design ไม่ต้องแตะโค้ด

## Answer

**มีของเขียนไว้แล้ว แต่แหล่งที่พึ่งได้เหลือแหล่งเดียว และฝั่งที่ map ต้องการที่สุดไม่มีใครเพาะให้ได้**

รายงานเต็ม: [`../research/01-scope-boundary-standards.md`](../research/01-scope-boundary-standards.md)

### ISCED-F 2013 — เพาะได้ แต่ราคาสามชั้น
UNESCO UIS *Detailed field descriptions* (2015) ให้ข้อความจริงทั้ง `Inclusions` และ
`Exclusions` — บทนำประกาศเจตนาตรงว่า *"Such exclusions help to better distinguish one
field from another"*. 84 detailed field, มี `Exclusions` 63 บล็อก. ตัวอย่าง 0913 Nursing
กัน veterinary/dental nursing และ non-medical care ออกโดยชี้รหัสปลายทางชัด; 0613 Software
กัน hardware (0714), computer use (0611), database/network (0612) ออกคม

เงื่อนไขพ่วง: **ต้องรหัส 4 หลัก** (2-3 หลักเป็นหัวข้อเปล่า ไม่มีคำอธิบาย) — intake ตอนนี้
ไม่ถาม `isced_code` เลย; `data/isced.py` มีแต่ code+name ต้อง import description เพิ่ม;
เป็นอังกฤษล้วน ไม่มีฉบับไทย. คุณภาพไม่สม่ำเสมอด้วย — 0917 Traditional medicine ทั้ง entry
คือประโยคเดียว ไม่มี exclusion

### มคอ.1 — เขียนขอบเขตไว้ดีที่สุด แต่ถูกยกเลิกทั้งชุดแล้ว
ขอบเขตอยู่ที่ **"๓. ลักษณะของสาขา/สาขาวิชา"** (ร้อยแก้ว สูตร "…ครอบคลุม…") และ
**"๘. เนื้อหาสาระสำคัญของสาขา"**. หัวข้อชื่อ "ขอบเขต/ขอบข่ายของสาขาวิชา" **ไม่มีจริง**
ใน 9 ฉบับที่เปิดได้

**กฎกระทรวง มาตรฐานคุณวุฒิระดับอุดมศึกษา พ.ศ. ๒๕๖๕ ข้อ ๒** ยกเลิก *"…มาตรฐานคุณวุฒิใน
สาขาหรือสาขาวิชา ทั้งนี้ ไม่ว่าในระดับใด สาขาใด หรือสาขาวิชาใด"* → **มคอ.1 ทุกฉบับตาย
ตั้งแต่ ก.ย. 2565**. ที่มาแทนคือผลลัพธ์การเรียนรู้ 4 ด้าน generic ล้วน และข้อ ๑๒ ของกฎกระทรวง
มาตรฐานหลักสูตรฯ ที่ระบุ 10 รายการที่หลักสูตรต้องมี — **ไม่มีข้อไหนเป็นขอบเขตสาขา**

ที่สำคัญกว่านั้น: grep `ไม่รวมถึง` / `มิได้ครอบคลุม` / `ไม่ครอบคลุม` ทั้ง 9 ฉบับ —
**เจอศูนย์ครั้ง**. มคอ.1 ไม่เคยเขียนฝั่งลบเลย

### AUN-QA — ทางตัน
Criterion 1 (Expected Learning Outcomes) ขอแค่ ELO ตาม taxonomy, aligned กับ vision/mission,
มาจาก stakeholder, แยก generic vs subject-specific. Keyword sweep v4.0 + v3.0:
`distinctive` 0, `unique` 0, `boundary` 0, `identity` 0; `scope` เจอแต่ในความหมาย
"ขอบเขตการประเมิน" → **ห้ามเขียนใน spec ว่า scope statement รองรับ AUN-QA Criterion 1**
ไม่มีข้อความรองรับ ถ้าจะอ้างมาตรฐาน อ้าง traceability (rule 2) กับ ISCED-F ได้ AUN-QA ไม่ได้

### ผลต่อ ticket 02
ควรเป็น **แบบฟอร์มมีของตั้งต้นและแก้ได้** ไม่ใช่กระดาษเปล่า — แต่:
- ตัวเพาะที่พึ่งได้มีอันเดียวคือ ISCED-F และมาพร้อมสามเงื่อนไขข้างบน (02 จะกำลังตัดสิน
  สามเรื่องพร้อมกัน ไม่ใช่หนึ่ง)
- มคอ.1 ใช้เป็น seed อัตโนมัติไม่ได้ (ถูกยกเลิก + ratchakitcha บล็อก + mua.go.th ตาย +
  `parsers/` ยัง stub) ใช้ได้อย่างมากเป็น **evidence ที่ designer แนบเอง** ฝั่ง requirement
- **ฝั่ง "ไม่รวมอะไร" ไม่มีมาตรฐานไหนเพาะให้ได้เป็นภาษาไทยเลย** — ซึ่งเป็นฝั่งที่ map บอกว่า
  เป็นหัวใจ (กัน Need "นอกสาขาเลย") → ต้องให้ designer เขียนเอง
- หลักฐานชี้ไปที่ **สองช่อง** (ครอบคลุม / ไม่รวมถึง) ไม่ใช่ free text ช่องเดียว —
  **ขัดกับที่ตกลงไว้ตอนวาง map** ต้องทบทวนที่ ticket 02
