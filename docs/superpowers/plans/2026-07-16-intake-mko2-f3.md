# F3 — ISCED Classification + Name Suggestion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้กรอกชื่อ/สาขาในหน้า Intake → กดปุ่ม → LLM จำแนกเข้า ISCED-F 2013 detailed field (จาก closed list ใน repo) + แนะนำชื่อหลักสูตรมาตรฐาน 2-3 ชื่อ → เลือกใช้ได้ → `isced_code` เก็บลง DB ตอน submit

**Architecture:** static taxonomy module (`data/isced.py`, ISCED-F 2013 broad/narrow/detailed) เป็น source of truth — prompt แนบ detailed list ทั้งหมด, service helper validate code ที่ LLM ตอบกลับก่อนคืนผล (retry 1 ครั้งถ้าไม่ผ่าน) และทับชื่อหมวดด้วยค่า taxonomy เสมอ. Endpoint stateless `POST /programs/suggest-isced` เหมือน F2's extract-metadata แต่ JSON body ธรรมดา (ไม่มีไฟล์). `isced_code` เป็น field optional บน `ProgramCreateRequest` เก็บลง DB nullable

**Tech Stack:** Python 3.11+, Pydantic v2 + Instructor, FastAPI, SQLAlchemy + Alembic, React 19 + TypeScript

**Spec:** `docs/superpowers/specs/2026-07-16-intake-mko2-f3-design.md`

## Global Constraints

- ทุกไฟล์ `.py` ขึ้นต้นด้วย `from __future__ import annotations`; type hints ทุก function signature
- Pydantic v2; `loguru` เท่านั้น (ห้าม stdlib `logging`); ห้าม hand-parse LLM JSON (Instructor เท่านั้น)
- Thai สำหรับ string ที่ผู้ใช้เห็น (รวม HTTPException detail); code/comment/variable อังกฤษ

- ต้องผ่าน `uv run ruff check src/ tests/`, `uv run mypy src/` (มี pre-existing errors — ห้ามเพิ่ม category ใหม่), `uv run pytest`

```python
async def suggest_isced(name_th: str, name_en: str, field: str) -> IscedSuggestion:
    """Classify a program into ISCED-F 2013 + suggest standard names.

    The LLM-returned code must exist in the embedded taxonomy. One retry is
    attempted (naming the invalid code) before giving up — field names in
    the result are always overwritten from the taxonomy, since the code is
    the source of truth, not whatever label the LLM produced for it.
    """
    messages = build_suggest_isced_prompt(name_th, name_en, field)
    result = await complete_light(IscedSuggestion, messages)
    taxonomy_field = get_detailed_field(result.isced_code)

    if taxonomy_field is None:
        retry_messages = build_suggest_isced_prompt(
            name_th, name_en, field, retry_invalid_code=result.isced_code
        )
        result = await complete_light(IscedSuggestion, retry_messages)
        taxonomy_field = get_detailed_field(result.isced_code)
        if taxonomy_field is None:
            raise ValueError(
                f"LLM ตอบ isced_code '{result.isced_code}' ซึ่งไม่อยู่ใน taxonomy หลัง retry"
            )

    return result.model_copy(
        update={
            "field_name_en": taxonomy_field.name_en,
            "field_name_th": taxonomy_field.name_th,
        }
    )
```

```typescript
async function handleSuggestIsced() {
  if (!form.name_th.trim() || !form.name_en.trim() || !form.field.trim()) {
    setIscedError('กรุณากรอกชื่อหลักสูตร (ไทย/อังกฤษ) และสาขาวิชาก่อน')
    return
  }
  setIscedLoading(true)
  setIscedError('')
  try {
    const resp = await api.post<IscedSuggestion>('/programs/suggest-isced', {
      name_th: form.name_th,
      name_en: form.name_en,
      field: form.field,
    })
    setIscedResult(resp.data)
  } catch (err: unknown) {
    const axiosErr = err as { response?: { data?: { detail?: string } } }
    setIscedError(
      axiosErr.response?.data?.detail ?? 'จำแนก ISCED ไม่สำเร็จ — ตรวจสอบว่า backend รันอยู่'
    )
  } finally {
    setIscedLoading(false)
  }
}

function useIscedSuggestion(name: SuggestedProgramName) {
  if (!iscedResult) return
  setForm(prev => ({ ...prev, name_th: name.name_th, name_en: name.name_en }))
  setIscedCode(iscedResult.isced_code)
}

function clearIscedCode() {
  setIscedCode('')
}
```
