# F2 — Document Upload → LLM Extract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้อัปโหลดเอกสารมหาวิทยาลัยในหน้า Intake → LLM สกัด vision/mission/เอกลักษณ์สถาบัน/อัตลักษณ์บัณฑิต → prefill ฟอร์ม (stateless, ไม่เก็บไฟล์)

**Architecture:** endpoint เดียว `POST /programs/extract-metadata` (multipart) → temp file → `parse_file` (unstructured, เรียกผ่าน `asyncio.to_thread`) → truncate 8k chars → `complete_light(ExtractedMetadata, ...)` → JSON. Frontend เพิ่ม toggle "กรอกเอง / อัปโหลดเอกสาร" — โหมดอัปโหลดโชว์กล่องไฟล์, ผล extract เติมเฉพาะช่องที่ยังว่าง

**Tech Stack:** Python 3.11+, Pydantic v2 + Instructor, FastAPI UploadFile (python-multipart 0.0.27 ติดตั้งแล้ว), unstructured (มีแล้ว), React 19 + TypeScript + axios v1

**Spec:** `docs/superpowers/specs/2026-07-15-intake-mko2-f2-design.md`

## Global Constraints

- ทุกไฟล์ `.py` ขึ้นต้นด้วย `from __future__ import annotations`; type hints ทุก function signature
- Pydantic v2; `loguru` เท่านั้น (ห้าม stdlib `logging`); ห้าม hand-parse LLM JSON (Instructor เท่านั้น)
- Thai สำหรับ string ที่ผู้ใช้เห็น (รวม HTTPException detail); code/comment/variable อังกฤษ
- LLM ห้ามแต่งข้อมูล — field ที่ไม่พบในเอกสาร = `null` (กติกาอยู่ใน system prompt)
- Endpoint stateless: ไม่แตะ DB/MinIO, temp file ลบใน `finally` เสมอ
- ต้องผ่าน `uv run ruff check src/ tests/`, `uv run mypy src/` (มี ~56 pre-existing errors — ห้ามเพิ่ม category ใหม่), `uv run pytest`
- Frontend ผ่าน `npm run lint` + `npm run build` (ไม่มี test runner)
- ค่าคงที่: `DOC_TEXT_LIMIT = 8_000` chars, max file 10 MB, min parsed text 50 chars, นามสกุลที่รับ `.pdf .docx .doc .txt`

เพิ่ม route **ก่อน** `@router.get("/{program_id}")` (declaration order ตาม spec):

```python
@router.post(
    "/extract-metadata",
    response_model=ExtractedMetadata,
    dependencies=[Depends(require_api_key)],
)
async def extract_metadata(file: UploadFile) -> ExtractedMetadata:
    """Parse an uploaded university document and LLM-extract intake prefill fields.

    Stateless: the file is parsed in a temp location and discarded — nothing
    is persisted. Runs before any program exists, so no program_id involved.
    """
    suffix = os.path.splitext(file.filename or "")[1].lower()
    if suffix not in _ALLOWED_EXTENSIONS:
        raise HTTPException(status_code=422, detail="รองรับเฉพาะไฟล์ PDF, DOCX, TXT")

    content = await file.read()
    if len(content) > _MAX_FILE_BYTES:
        raise HTTPException(status_code=413, detail="ไฟล์ต้องไม่เกิน 10 MB")

    # Lazy import: unstructured is heavy and only needed on this endpoint —
    # keep it out of API startup and test collection.
    from curriculum_agent.parsers.tika_parser import parse_file

    tmp_path = ""
    try:
        with tempfile.NamedTemporaryFile(suffix=suffix, delete=False) as tmp:
            tmp.write(content)
            tmp_path = tmp.name
        try:
            text = await asyncio.to_thread(parse_file, tmp_path)
        except Exception as exc:
            logger.warning(f"Document parse failed ({file.filename}): {exc}")
            raise HTTPException(status_code=422, detail="อ่านเนื้อหาจากไฟล์ไม่ได้") from exc
        if len(text.strip()) < _MIN_TEXT_CHARS:
            raise HTTPException(status_code=422, detail="อ่านเนื้อหาจากไฟล์ไม่ได้")
        try:
            return await extract_metadata_from_text(text)
        except Exception as exc:
            logger.error(f"Metadata extraction failed: {exc}")
            raise HTTPException(
                status_code=502, detail="สกัดข้อมูลไม่สำเร็จ กรุณาลองใหม่หรือกรอกเอง"
            ) from exc
    finally:
        if tmp_path:
            os.unlink(tmp_path)
```

- `NamedTemporaryFile(delete=False)` + ปิดผ่าน context manager ก่อน parse — จำเป็นบน Windows (เปิดไฟล์ซ้ำระหว่างยังเปิดอยู่ไม่ได้)
- lazy import `parse_file` ใน function — `unstructured` โหลดช้า; import ที่ module level จะถ่วง API startup และ test ทุกตัวที่ import `app`. test patch ที่ `curriculum_agent.parsers.tika_parser.parse_file` จึงยังใช้ได้ (resolve ตอนเรียก)

```typescript
async function handleExtract() {
  if (!docFile) {
    setExtractMessage('กรุณาเลือกไฟล์ก่อน')
    return
  }
  setExtracting(true)
  setExtractMessage('')
  try {
    const fd = new FormData()
    fd.append('file', docFile)
    const resp = await api.post<ExtractedMetadata>('/programs/extract-metadata', fd)
    const data = resp.data
    // Compute the merge OUTSIDE the state updater — React StrictMode runs
    // updaters twice, which would duplicate side effects like filled.push.
    const filled: string[] = []
    const updates: Partial<FormState> = {}
    ;(Object.keys(FIELD_LABELS) as (keyof ExtractedMetadata)[]).forEach(key => {
      const value = data[key]
      if (value && !form[key].trim()) {
        updates[key] = value
        filled.push(FIELD_LABELS[key])
      }
    })
    if (filled.length > 0) {
      setForm(prev => ({ ...prev, ...updates }))
    }
    setExtractMessage(
      filled.length > 0
        ? `เติมข้อมูลแล้ว ${filled.length} รายการ (${filled.join(', ')})`
        : 'ไม่พบข้อมูลในเอกสาร'
    )
  } catch (err: unknown) {
    const axiosErr = err as { response?: { status: number; data?: { detail?: string } } }
    setExtractMessage(
      axiosErr.response?.data?.detail ??
        'สกัดข้อมูลไม่สำเร็จ — ตรวจสอบว่า backend รันอยู่'
    )
  } finally {
    setExtracting(false)
  }
}
```

```tsx
              กรอกข้อมูลเอง
            </button>
            <button
              type="button"
              onClick={() => setEntryMode('upload')}
              className={`px-4 py-1.5 transition-colors ${
                entryMode === 'upload'
                  ? 'bg-blue-600 text-white'
                  : 'bg-white text-gray-600 hover:bg-gray-50'
              }`}
            >
              อัปโหลดเอกสารมหาวิทยาลัย
            </button>
          </div>

          {entryMode === 'upload' && (
            <div className="bg-blue-50 border border-blue-100 rounded-lg p-4 space-y-3">
              <p className="text-xs text-gray-600">
                อัปโหลดเอกสาร (มคอ.2 เดิม, ธรรมนูญ, SAR ฯลฯ) ระบบจะสกัดวิสัยทัศน์ พันธกิจ
                เอกลักษณ์สถาบัน และอัตลักษณ์บัณฑิตมาเติมในช่องที่ยังว่างให้อัตโนมัติ
              </p>
              <div className="flex items-center gap-3">
                <input
                  type="file"
                  accept=".pdf,.docx,.doc,.txt"
                  onChange={e => setDocFile(e.target.files?.[0] ?? null)}
                  className="text-sm text-gray-600 file:mr-3 file:px-3 file:py-1.5 file:rounded-lg file:border-0 file:bg-white file:text-blue-600 file:text-sm file:cursor-pointer"
                />
                <button
                  type="button"
                  onClick={handleExtract}
                  disabled={extracting || !docFile}
                  className="bg-blue-600 hover:bg-blue-700 disabled:bg-blue-300 text-white text-sm font-medium rounded-lg px-4 py-1.5 transition-colors cursor-pointer disabled:cursor-not-allowed shrink-0"
                >
                  {extracting ? 'กำลังสกัดข้อมูล…' : 'สกัดข้อมูล'}
                </button>
              </div>
              {extractMessage && (
                <p className="text-xs text-blue-700">{extractMessage}</p>
              )}
            </div>
          )}
        </div>
```
