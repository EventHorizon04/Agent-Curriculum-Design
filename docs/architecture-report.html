Bug Findings & Fixes

#01
interrupt() return value ถูกทิ้ง — HITL edits หายทั้งหมด
src/curriculum_agent/graph.py :83–100
Critical
ปัญหา
4 review nodes เรียก interrupt(...) แต่ทิ้ง return value ทำให้ designer edits ที่ส่งผ่าน graph.aupdate_state() ไม่เคยถูก merge เข้า state
Failure Scenario
Designer แก้ classified_evidence แล้ว resume graph → node return state เดิม → downstream stages เห็นข้อมูลที่ไม่ได้แก้ไข → HITL feature ไม่ทำงาน

04

Architecture Assessment

FastAPI Dependency Injection Fixed
Module-level repo singletons ใน API routes bypass FastAPI DI → ไม่สามารถ inject test sessions ได้

Fix: ย้าย instantiation เข้า function, เพิ่ม require_api_key dependency บน write endpoints ทุก route (programs, plos, evidence)
Authentication Layer Added
ไม่มี auth บน write endpoints → ใครก็ trigger pipeline ได้

Fix: เพิ่ม X-API-Key header check ผ่าน APIKeyHeader + settings.api_key; dev mode (key=None) ผ่านอัตโนมัติ; prod ต้อง set env var
LangGraph HITL Pattern Fixed
LangGraph interrupt() returns designer payload on resume — ต้อง merge ไม่ใช่ทิ้ง

Pattern: payload = interrupt(msg); return {**state, **payload} if isinstance(payload, dict) else state
Async Client Lifecycle Fixed
AsyncOpenAI ไม่ควรสร้างที่ module level — event loop ไม่มีการรับประกัน

Pattern: @functools.cache บน factory function = lazy singleton ที่ปลอดภัยข้าม event loop
