CURRICULUM
DESIGN AGENT

AI Agent ช่วยออกแบบหลักสูตรอุดมศึกษาไทย ตามมาตรฐาน MHESI และหลักการ OBE — 5-stage LangGraph pipeline

v0.1.0 PoC Python 3.11+ uv · Docker Compose 40 Tests Passing
01
Environment Setup
คัดลอก env file และแก้ค่าตามต้องการ
cp .env.example .env # ค่าสำคัญใน .env ที่ควรแก้ LIGHT_MODEL=scb10x/typhoon2-8b-instruct # Typhoon2 8B — classification + SMART HEAVY_MODEL=qwen2.5:14b # Qwen 14B — PLO/YLO synthesis (หรือ :32b) # API_KEY=change-me-in-production # uncomment เมื่อ deploy จริง
02
Start Docker Services
เปิด infrastructure ทั้งหมดด้วยคำสั่งเดียว
docker compose up -d
ca-ollama :11434 LLM inference — Typhoon2-8B + Qwen2.5
ca-postgres :5432 Structured data — Programs, PLO, YLO, Evidence
ca-minio :9000 / :9001 Object storage — raw documents + หลักสูตร files
ca-api :8000 FastAPI backend — REST endpoints + LangGraph runner
ca-ui :8501 Streamlit frontend — UI หลักสำหรับ curriculum designers
03
Pull LLM Models
ดาวน์โหลด models เข้า Ollama — ทำครั้งแรกเท่านั้น ใช้เวลาสักครู่
# Light model — Typhoon2 8B (classification, SMART validation) docker exec ca-ollama ollama pull scb10x/typhoon2-8b-instruct # Heavy model — เลือกตาม VRAM ที่มี docker exec ca-ollama ollama pull qwen2.5:14b # VRAM < 24 GB docker exec ca-ollama ollama pull qwen2.5:32b # VRAM 24 GB+
04
Install Python Deps + Migrate DB
ต้องทำก่อนเปิด API ครั้งแรก
# ติดตั้ง dependencies ทั้งหมด (รวม extras สำหรับ NLP) uv sync --all-extras # Run Alembic migrations — สร้าง tables ใน PostgreSQL uv run alembic upgrade head
→

# Streamlit — hot-reload เมื่อแก้ไข streamlit_app/ uv run streamlit run streamlit_app/app.py
